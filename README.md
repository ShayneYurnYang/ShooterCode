# Shooter Testing

A WPILib-based Java project for testing FRC shooter subsystem mechanisms and vendor hardware integration.

## Key Features

* **FRC Java Framework:** Built on WPILib for FRC robot control.
* **Hardware Libraries:** Pre-configured support for REV Hardware (`REVLib`), Kaua'i Labs `NavX`, and WPILib Command-Based programming.

## Requirements

* Java 17+ / WPILib Development Environment
* Gradle (via included Gradle Wrapper)
